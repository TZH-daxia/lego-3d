# 模拟乐高拼图 · 3D Brick Studio

在浏览器里用 3D 积木搭乐高的拼图编辑器。

## 技术栈

- Vite
- React 19 + TypeScript
- React Three Fiber / three.js（3D 渲染）
- Zustand（状态管理）

## 运行方式

```bash
npm install
npm run dev      # 开发模式，http://localhost:5173
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

需要 Node 18+。

## 操作说明

**拼图管理**

- 左上角「新增拼图」创建一个新作品
- 列表每行右侧的「⋮」：重命名（名字原地变输入框，回车保存、Esc 取消）、删除（二次确认）
- 右上角是 **编辑 / 保存**：保存会落盘并切到观察模式，零件盒锁定不可点

**搭积木**

- 点底部零件盒里的格子，取一个零件，自动落到托盘空位上
- 选中方块后，点零件盒上方的色板改颜色
- 右侧操作台：前 / 后 / 左 / 右 + 上升 / 下降（也可用 `W A S D`、`E` / `Q`）
- 选中方块右侧浮出四个图标：向上翻 / 向下翻 / 向左转 / 向右转，点一下转 90°
- `Delete` / `Backspace` 删除选中方块，`Esc` 取消选中

**组装规则**

- 零件之间不会互相穿插
- 落点底面每一格都必须扣在下方凸点上：平滑片、圆柱边缘、斜面坡面、翻转件的顶面都算没有凸点
- 想叠高就等下层铺满，新零件会自动落到上一层

**视角**

- 左键拖拽旋转、滚轮缩放、右键拖拽平移
- 右上角罗盘本身就是按钮，点一下回到默认正前方视角

**零件盒**

- 默认展示全部零件，按 砖类 → 板类 → 特殊件 排列，颜色随机、取用不限量
- 拖动零件盒顶部那条把手可以调高度（双击恢复默认），装不下时在盒内滚动
