# 乐高拼图 · 3D Brick Studio

基于 **Vite + React 19 + TypeScript + React Three Fiber** 的 3D 乐高拼图编辑器。

## 运行

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # 产物输出到 dist/
```

需要 Node 18+（本项目在 Node 22 下开发）。

## 已实现的功能

### 左侧拼图会话列表
- 顶部「新增拼图」按钮，每新建一个就是一个独立的拼图作品
- 每行显示俯视缩略图、名称、模式标签、方块数、更新时间
- 双击名称可重命名，悬停出现删除按钮，**删除前弹二次确认小窗**（取消 / 删除）
- 全部数据自动写入 `localStorage`，刷新不丢

### 右侧预览 + 操作区
- 3D 场景（乐高托盘）：32×32 乐高底板、阴影、可自由旋转/缩放/平移的相机
- **默认视角正对底板正前方**（相机方位角为 0），所以屏幕的上下左右就是托盘的前后左右，
  `W / A / S / D` 走的就是画面上"笔直"的前 / 左 / 后 / 右
- **右上角工具带**：左边是 **方向罗盘**（跟着相机方位一起转，标出托盘的 前/后/左/右
  与对应的 `W/A/S/D`，下面「重置视角」一键回正），右边是 **编辑 / 保存** 图标按钮，两者顶部对齐
- **保存** = 落盘并进入「观察模式」：下方零件盒整体锁定，只看不点
- **编辑** = 解锁零件盒，恢复取件与操作

### 底部零件盒（容器方格）
- **一个外框 + 连续网格线**的方格盘：固定 **8 列**、默认 3 排
- **格子是 60px 正方形且尺寸恒定**：只由 `--cell` 决定，所以 `＋一排 / −一排`
  只改变高度，不会把格子变大变小（排数超出高度时整体纵向滚动）
- 每个格子放「同一种造型 + 同一种颜色」的多个零件，
  **数量角标固定在格子右上角内侧**，不会被裁掉也不压住图形主体
- **点空格子 = 新增**：弹出零件弹窗，选造型（砖块 / 薄板 / 特殊件 分组）、选颜色、填数量
- **点非空格子 = 取件**：取 1 件放进托盘（3D 底板），格子数量 -1；取完变成虚化的「补货」格子，再点一下就能按原造型补货
- **拖动格子里的东西换位**：按住非空格子拖到另一格即可交换两个格子的内容（含空格），支持鼠标与触屏
- 悬停格子左上角出现 ✎（改造型 / 颜色 / 数量）与 ✕（清空）两个小按钮
- `＋ 一排` / `− 一排` 增减排数（最后一排还有零件时不允许删）
- 初始零件盒前两排共 16 件常用件：2×2 / 1×2 / 1×1 / 1×4 / 2×4 / 2×3 砖、
  2×4 / 1×2 / 1×4 / 2×6 薄板、1×1 / 2×2 圆柱、2×2 圆薄板、1×1 平滑片、2×2 / 2×4 斜面
- **每个格子里的图标都是等轴测（斜视）视图**：顶面 + 右侧面 + 前侧面 + 凸点，
  圆柱用横向渐变表现柱面，斜面的平顶比例与坡向都和 3D 几何体完全一致
- 新增方块会从底板中心向外找空位自然落下（有掉落 + 弹入动画）

### 色板
- 12 种官方乐高配色，就放在零件盒**上方**、和零件盒左对齐，右边是 `＋一排 / −一排`
- 选中方块后：点色块直接替换选中方块的颜色（选中时色板同步高亮）
- 新零件的颜色在零件弹窗里选，和色板互不干扰

### 移动与旋转（格子不重叠）
- **移动**：同层前后左右 + 上升 / 下降，全部按钮操作
- **旋转**：左右旋转（绕 Y 轴）+ 上下旋转（绕 X 轴），90° 步进
  - 旋转时保持水平中心不动，旋转后包围盒自动重算
- 移动 / 旋转前都会做占位检测，**目标格已被占用时不会执行**，改为播放
  - 位移方向的回弹抖动 + 红色高亮闪烁
  - 旋转被挡时原地扭动 + 红闪
- 选中方块用 **白色描边 + 地面落点投影**表示，**不再给材质加发光**，
  所以方块的颜色和零件盒里选的颜色完全一致
- **点击选中**：场景里点方块即可选中，描边与地面投影都是纯视觉件，**已退出射线检测**，
  不会挡住旁边方块的点击；新增方块会先铺满底板、再往上叠，不会在中心堆成难点的高塔
- **选中后积木右侧浮出一列透明图标**：就是操作台「旋转」区那四个动作
  （`⇧T` 向上翻转 / `T` 向下翻转 / `⇧R` 向左旋转 / `R` 向右旋转），
  点一下转 90°，**可以连着点**，按钮不会因为旋转而消失（按钮在画布容器之外，
  不会把点击传给 3D 场景，也就不会触发"点空白取消选中"）
- 浮动按钮的位置由画布内的 `AnchorTracker` 每帧把「积木右边缘」这个世界坐标投影成屏幕坐标，
  用 `translate3d` 写到按钮上，所以视角旋转、缩放、积木移动/旋转它都跟得住
- **点空白处取消选中**；拖动视角（位移 > 4px）不算点击，不会误取消
- **按住方块不会带动视角**：指针落在方块上时会临时关掉 OrbitControls，
  抬手（或 pointercancel）立刻恢复，所以"按住零件"不会变成"转视角"

### 快捷键盘

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 前后左右移动 |
| `E` / `PageUp`、`Q` / `PageDown` | 上升、下降一层 |
| `R` / `Shift+R` | 左右旋转 / 回转 90° |
| `T` / `Shift+T` | 上下旋转 / 回转 90° |
| `Delete` / `Backspace` | 删除选中方块 |
| `Esc` | 取消选中 |

## 核心实现说明

### 格点模型
- 水平 1 格 = 1 个凸点间距，垂直 1 格 = 1 个板高（真实乐高 1 砖 = 3 板高）
- 方块以「最小角」为锚点，坐标全部为整数
- 旋转限制为 90° 步进，因此旋转后方块依然是轴对齐包围盒，
  尺寸只是 `(w, h, d)` 的换位，占地判定依旧可以把每个方块拆成整数格

### 碰撞检测
`src/lib/grid.ts` 把整个场景构建成一个占位索引：

```ts
cells: Map<`${x},${y},${z}`, brickId>
```

移动/旋转前只检查目标包围盒覆盖的那几个格点，
复杂度是 O(占地面积)，与场景里方块总数无关。

### 动画
`src/components/scene/Brick.tsx` 全部用 `useFrame` + 阻尼插值实现：
- 位置：指数阻尼跟随目标格点，移动平滑不跳变
- 旋转：`nearestAngle` 取最短角，保证只转 90° 而不是绕 270°
- 出生：从高处落下 + `easeOutBack` 缩放弹入
- 碰撞：正弦衰减抖动 + `emissive` 红色闪烁

### 乐高几何
`src/components/scene/brickGeometry.ts` 按造型缓存并复用几何体：
- 砖/板/平滑片 → `RoundedBoxGeometry`（圆角）
- 圆柱 → `CylinderGeometry`
- 斜面 → `THREE.Shape` 梯形剖面 + `ExtrudeGeometry`
- 凸点 → `mergeGeometries` 合并成一个几何体，每个方块最多 2 个 draw call
- 底板 1024 个凸点用 `InstancedMesh`

### 交互性能（为什么不该卡）
- **阴影按需刷新**：three 默认每帧重画 directional light 的 2048² shadow map，即使场景里
  什么都没有动。现在 `shadowMap.autoUpdate = false`，只有方块在动画中
  （位移 / 旋转 / 出生 / 碰撞抖动）才置脏重算 —— 闲置时主线程与 GPU 完全空出来
- **弹窗不用 `backdrop-filter`**：全屏实时模糊要对不停重绘的 WebGL 画布逐帧采样，
  是"点开弹窗卡一下"的主因；改成纯色遮罩后开合都是合成层动画
- **格子重绘隔离**：`.part-cell { contain: paint }`，悬停只重绘当前格子；
  悬停高光用伪元素做透明度过渡，避免每帧重画渐变
- **罗盘不触发 React 重渲染**：方位角由画布内的 `CameraBridge` 每帧直接写进 DOM 的 CSS 变量

### 2D 等轴测图标
`src/components/ShapeIcon.tsx` 用同一套等轴测公式把造型投影成图标：

```
屏幕 x = cos30° · (u - v)
屏幕 y = sin30° · (u + v) - t
```

- 砖/板：顶面 + 右侧面 + 前侧面，凸点用 `matrix(K,H,-K,H,...)` 变换的椭圆贴在顶面上
- 斜面：顶面只留后半段，多画一块 45° 斜面
- 圆柱：顶面椭圆 + 侧壁（按角度采样描出两段椭圆弧 + 两条竖直切线）
- 每个图标按自身包围盒自适应缩放，保证形状看得清；颜色面用同一色相做明暗分层

### 零件盒交互
`src/components/container/` 下：
- `ContainerGrid.tsx` 容器骨架：4 种操作分别走 store 的 `setContainerCell / takeFromCell / swapContainerCells / addContainerRow`
- `PartCell.tsx` 纯展示的格子（点击取件 / 拖动换位 / 悬停编辑）
- `PartDialog.tsx` 零件弹窗（造型分组 + 官方 12 色 + 数量步进），用 `createPortal` 挂到 body
- `usePartDrag.ts` **基于 pointer 事件**的拖拽（不是原生 HTML5 drag）：
  超过 6px 才算拖动，`setPointerCapture` 保证指针移出格子也能收到事件，
  拖动结束后会吞掉浏览器补发的 click，避免误取件

## 目录结构

```
src/
├─ components/
│  ├─ scene/          3D 场景：底板、方块、几何体生成
│  ├─ container/      底部零件盒：格网、格子、零件弹窗、拖拽
│  ├─ Sidebar.tsx     左侧拼图列表
│  ├─ Editor.tsx      右侧舞台 + 底部工作区
│  ├─ Toolbar.tsx     编辑 / 保存
│  ├─ ColorPalette.tsx 色板（给选中方块改色）
│  ├─ ControlPad.tsx  移动 / 旋转 / 删除 / 清空
│  ├─ ShapeIcon.tsx   方块等轴测图标
│  └─ MiniPreview.tsx 缩略图
├─ data/              方块造型目录 + 官方色板 + 容器默认值
├─ lib/               格点算法 + 本地存储
├─ store/             zustand 状态
├─ types.ts
└─ styles.css
```
